> **Як читати статуси:** `Done` — артефакт чи результат підтверджений у GitHub (гілка `main`, Issues); `In review` — матеріал існує, але ще потребує рецензії, злиття або усунення неузгодженості; `In progress` — робота триває; `To do` — артефакт відсутній чи робота не підтверджена; `Blocked` — виконанню заважає конкретна зовнішня перешкода. Статус `Done` ставить СМ лише коли артефакт є в `main`.
