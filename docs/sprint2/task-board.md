## 6. Definition of Done — контроль результатів

- [ ] Є справжні незалежні аркуші всіх 5 учасників; кожен розділ перевірили щонайменше двоє.
- [ ] ≥20 дефектів підтверджені реально; ≥2 на кожний критерій; автори й рішення зафіксовані.
- [ ] SRS 1.1 узгоджена: зміни тільки з реєстру, ID стабільні, рішення замовника внесені.
- [ ] Test Plan: 7 рівнів, ≥15 типів, Ціль/Опис/дані/пріоритет/середовище/обґрунтування «Ні».
- [ ] Аудитор-опонент переніс прийняті рішення до «Спірні» і підготував 5 питань.
- [ ] Demo проведено, peer-review форми заповнено учасниками.
- [ ] Проведено Retro; реальні Start/Stop/Continue та рішення записано.
- [ ] Додано `requirements-defects.xlsx` і `task-board.xlsx` або погоджені еквіваленти.

**Контроль формату:** перед здачею зберігайте синхронну версію [task-board.xlsx](task-board.xlsx) або затверджений GitHub Projects.
