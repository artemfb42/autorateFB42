
# Незалежний аудит SRS 1.0 — АвтоРейт

## 1. Призначення

Ця папка містить особисті аркуші перевірки вимог SRS 1.0 «АвтоРейт».

**Джерело:** [SRS 1.0](../SRS_05_АвтоРейт.pdf).

Кожен учасник перевіряє свої розділи незалежно від інших за шістьма критеріями якості вимог.

## 4. Правила перевірки

Кожна знахідка повинна містити:

- ID вимоги або точне місце її розташування.
- Критерій якості та пункт чек-листа.
- Фрагмент початкової вимоги.
- Обґрунтування дефекту.
- Готове формулювання виправлення.
- Питання замовнику, якщо потрібне уточнення.

## 5. Об'єднання результатів

Після особистого підтвердження знахідок тест-аналітик:

1. Збирає незалежні результати всіх учасників.
2. Вилучає дублікати без втрати інформації про авторів.
3. Передає спірні записи аудитору-опоненту.
4. Вносить прийняті дефекти в загальний реєстр.
5. Зберігає посилання на авторів і підстави виправлень.

**Загальний реєстр:** [requirements-defects.md](../requirements-defects.md).

Наявність оформленого аркуша не замінює особистої перевірки його змісту відповідним учасником.
