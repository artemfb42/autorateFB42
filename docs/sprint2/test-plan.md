# Sprint 2 — План тестування «АвтоРейт»

**Відповідальний:** Найда Владислав (Test Engineer). **Версія:** 1.0-draft, 13.10.2026.  
**Джерела:** SRS 1.0 `SRS_05_АвтоРейт.pdf`, [проєкт SRS 1.1](SRS-1.1.md), вимоги методички Sprint 2.  
**Мета:** визначити 7 рівнів і перевірити застосовність кожного з 24 типів, дати **Ціль + Опис + Пріоритет + інструменти + тестові дані + статус середовища**.

## 1. Продукт, обсяг і ризики

**Об'єкти:** веб-SPA AutoRate (Login/Register, марка, модель, голос/коментар, Overall Rating, Profile) та майбутній Java 17-модуль `autorate-module` (`RatingAggregator`, `VoteValidator`, `ModelSearch`). **Поза обсягом v1.0:** інтерфейс модератора, UI адміністратора каталогу, мобільний застосунок (SRS 1.0, §1.2).

**Основні ризики:** два голоси за модель від однієї пари userId/modelId, нерозрізнення ваг репутації, колізії рангу/порога голосів, порожні або заборонені коментарі, обхід доступу після Logout, нестабільна пагінація та пошук.

**Реально описані у SRS ресурси:** публічне `https://buggy.justtestit.org` зі спільною базою, Chrome/Firefox для desktop; Java-модуль описаний як Maven/JUnit 5. **До наданих у цьому завданні файлів вихідний Java-модуль і окремий локальний вебстенд НЕ входять.** Тому нижче розрізняються предметна застосовність і фактична готовність до виконання.
