
# АвтоРейт — План тестування (Sprint 2)

> **Статус:** план / проєкт; це стратегія майбутніх перевірок, а не журнал уже виконаних тестів. Кількісні SLO та невизначені правила набудуть чинності після затвердження SRS 1.1.

**Версія:** 0.9 (на рецензії)  
**Дата підготовки:** 13.10.2026  
**Відповідальна роль:** інженер з тестування (Найда Владислав), до затвердження Test Lead  
**Основа:** SRS 1.0 «АвтоРейт», проєкт `SRS-1.1.md`, легенда продукту, методичка Sprint 2.

## 1. Продукт, межі та мета

**Мета:** визначити перевірювану стратегію якості рейтингу, голосування, авторизації, профілю та пошуку. **У межах:** UI SPA, класи Java-модуля, основні бізнес-правила; **поза межами:** інтерфейс адміністрування й модерації, мобільний застосунок (не входять до версії 1.0).

**Ключові ризики:** накрутка голосів, подвійне прийняття паралельних запитів, некоректні ваги репутації, розбіжність UI/BL на коментарях, доступ до профілю без сеансу, хибний пошук та порядок рейтингу.

## 5. Інструменти, середовища і тестові дані

### 5.1. Середовища
- **Публічне demo:** https://buggy.justtestit.org — лише помірні ручні позитивні/негативні функціональні сценарії на власних тестових акаунтах; без навантаження, сканування або перебору.
- **Локальний резерв / контрольований стенд:** потрібен для одночасного голосування, навантаження, fail/recovery і експериментів із БД; доступ і параметри має надати/погодити викладач.
- **Java-модуль:** JDK 17, Maven, JUnit 5; для профілювання JFR/VisualVM.

### 5.2. Мінімальний контрольований набір
- Тестові облікові записи `T2-A`, `T2-B`, `T2-C` з різними репутаціями 1/2/3 (якщо поле доступне на стенді).
- Моделі з 0, 1, 2, 3, 4, 5 голосами для перевірки вибраного порогу рейтингу.
- Оцінки 0, 1, 5, 6; коментарі 0, 1, 200, 201 символів; `null`, пробіли, слово `spam`, текст зі складним Unicode.
- Запити пошуку: порожній, лише пробіли, `lam`/`LAM`, точна назва марки/моделі, відсутній префікс.
- Для навантаження — ізольовані генератори даних; не створювати сотні записів у публічному demo.

## 6. Ризики, залежності, припущення і критерії виходу

| Ризик / залежність | Вплив | Запобіжна дія |
|---|---|---|

| Немає локального стенда | Частина інтеграційних / перформанс / race перевірок недоступна | Відмітити як заплановані / blocked до отримання стенда; не запускати на demo |

**Примітка:** цей файл не стверджує, що тести вже виконані, локальний стенд розгорнутий чи замовник прийняв числові критерії.
