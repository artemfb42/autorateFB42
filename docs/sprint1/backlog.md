## Мета backlog
Backlog містить user stories для функціональності «Особистий кабінет та рейтинг тижня», а також пов'язані з нею вимоги для ролей «Зареєстрований користувач», «Відвідувач», «Модератор» та «Адміністратор каталогу».

Пріоритет визначено з урахуванням впливу функції на основну цінність продукту, безпеку та коректність рейтингу. Функції, що безпосередньо впливають на достовірність рейтингу або безпеку облікового запису, мають вищий пріоритет. Допоміжні адміністративні функції можуть мати нижчий пріоритет.

## Обґрунтування пріоритетів

**High** — функціональність безпосередньо впливає на основну цінність продукту, достовірність рейтингу, безпеку облікового запису або основний сценарій роботи користувача.  
**Medium** — функціональність важлива для повноцінної роботи користувачів і модераторів, але не є критичною для базового сценарію.  
**Low** — функціональність корисна для підтримки продукту, але може бути реалізована після основних сценаріїв.
