# Папка для моделей BPMN.
# BPMN-моделі процесів проєкту

У цьому розділі містяться BPMN-діаграми та супровідна документація до бізнес-процесів, розроблених у межах Спринту 1.

---

## Інструменти та відкриття файлів

* **Інструменти розробки:** [bpmn.io](https://demo.bpmn.io/)
* **Формати файлів:**
  * `.bpmn` — вихідні файли діаграм у форматі XML.
  * `.SVG` — графічні експорти для швидкого перегляду.
  * `.pdf` — завантаження діаграм в зручному форматі.
* **Як відкрити вихідний файл:**
1. Зайдіть на [bpmn.io](https://demo.bpmn.io/).
2. Перетягніть необхідний `.bpmn` файл із цієї папки у вікно браузера.
