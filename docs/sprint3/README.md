| Перевірка | Прояв | Результат |
|---|---|---|

Описані перевірки відповідають, щонайбільше, **двом різним рівням Severity** (Major і Minor); методичка для п'яти осіб вимагає **три дефекти різних рівнів Severity**. Тому для повного DoD потрібно незалежно відтворити ще один дефект рівня **Normal** або переглянути склад трьох основних перевірок і зафіксувати це в `audit.md`. Також необхідно виправити залишкові неузгодженості Bug ID й формулювань, якщо вони є.

## 9. Підготовка до демонстрації

За методичкою демо — **10 хвилин**: 2 хв покриття та статистика; 4 хв живе виконання позитивного і негативного кейсу; 3 хв два дефекти різного Severity з поясненням; 1 хв складнощі та висновки. Після демо — Retro за схемою **Start / Stop / Continue**.

## 10. Правила роботи з публічним demo

Під час тестування використовувалися тільки тестові дані. На публічному demo заборонені навантажувальні перевірки, зміни чужих облікових записів, реальні персональні дані та атакувальні рядки. Повторні перевірки виконувати обережно, не порушуючи роботу інших користувачів.
